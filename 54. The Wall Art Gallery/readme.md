# The Wall Art Gallery (Flask + REST API)

> To try this project live, [click here](https://the-wall-art-gallery.onrender.com/) *(free-tier instances may take 30–50s to wake up).*


A Flask website that displays public-domain artworks on a gallery wall.

## Description

This project connects to the Art Institute of Chicago API to search artworks, browse by topic, and view detailed pages for each piece.  
It demonstrates working with REST APIs, including pagination, an image proxy, response caching, and custom error pages. No API key is required.
