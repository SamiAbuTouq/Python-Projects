# Space Invaders (Python + Turtle)

## Overview

A neon-styled remake of the classic Space Invaders arcade game.

## Description

The player moves a ship and fires at waves of pixel-art aliens that speed up and get tougher with each level.  
The game includes different alien types with different points, a bonus UFO, lives and scoring, pause support, and keyboard controls for both arrow keys and A/D.
