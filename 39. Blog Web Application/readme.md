# Blog Web Application (Flask)

> To try this project live, [click here](https://blog-1mmy.onrender.com/) *(free-tier instances may take 30–50s to wake up).*


A full-featured blog web application built with Flask.

## Description

This project allows users to register, log in, create blog posts, and leave comments on posts.  
It includes role-based access control for admin actions, rich text editing with CKEditor, user authentication, and database-backed content management.
