# 100 Days of Python – Course Projects

This repository contains projects built during the **[100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/course/100-days-of-code/)** Udemy course, covering Python from the basics to advanced concepts through hands-on, real-world projects.

## Projects
Each project is a practical exercise or mini-application, organized in its own folder with a dedicated `README.md` explaining its purpose and functionality. Together they cover scripting, automation, web development, APIs, databases, authentication, and GUI applications.

These projects were created for **learning and practice purposes** and demonstrate incremental progress in Python development skills.
